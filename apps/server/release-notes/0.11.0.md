Emoji reactions with reaction roles, collapsible categories with the number of unread messages, and notices: messages shown without their author. Four database migrations, so back up first. Desktop app 0.13.0 brings the same client to the app.

## Before you update

- **Back up first.** This version adds four database migrations: the tables for reactions and reaction roles, a flag per message for notices, and two new rights handed to existing roles (next point). Migrations run at the start and cannot be undone. No new variable, nothing to set by hand: installations with automatic updates take this version by themselves once it is published.
- **Two new rights, given to existing roles by the update.** "Reagieren" (add emoji reactions) goes to every role that may write messages, so "Mitglied" gets it and "Gast" does not. "Hinweise setzen" (show a message without its author) goes to every role that may delete other people's messages; your default roles do not have that, so only roles you made get it. Owners and administrators have both anyway. Check Verwaltung > Rollen if you want it otherwise; both rights can be overridden per channel.
- **Desktop app:** 0.13.0 carries the same client. Older apps keep working with this server, but show none of the three new features; the browser client comes with the server.
- **Directory:** nothing to do. Reactions in direct messages travel inside the encrypted messages; the public Squorli directory already understands them.

## New

- **Emoji reactions.** Members react to a message with the emoji picker from the message's toolbar; the chips under the message show who reacted. Who may react is the new right "Reagieren", server-wide or per channel. Reactions work in direct messages too, between people whose apps have them.
- **Reaction roles.** A moderator ties an emoji on a particular message to a role: whoever reacts with it gets the role, so members can accept your rules with one click. Set up with the shield in the message's toolbar or under Verwaltung > Reaktionsrollen, with a switch per rule whether removing the reaction removes the role. A configured emoji needs no right to react, so a guest can accept the rules.
- **Collapsible categories.** A click on a category's heading folds its channels away. The folded heading shows how many unread messages the category holds, a badge for mentions, and how many people sit in its voice channels. Each member's choice is kept per device.
- **Notices.** With the right "Hinweise setzen", any message of a channel can be shown as a notice: no avatar and no name, only the time at the left edge and the text next to it. The megaphone in the message's toolbar sets it and takes it back; the author's own rights are unchanged.

## Improved

- **The installers show what they are doing.** The install script shows the image pull and the signature check as they run instead of a silent pause, and the long steps of the Windows setup show that they are alive.
- **A fresh installation with the install script** no longer stops at the question about the storage quota, and when a directory is used the Squorli account is offered as the default owner.

## Fixed

- **Link previews** could give up their worker thread for good when the first page to read arrived before the thread had reported itself ready; the preview of that page and of every later one was then made on the main thread. The first page now waits for the thread.
