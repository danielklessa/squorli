A link to your server's privacy policy under the form that creates a server account, and the new address of the source repository.

## Before you update

- **Nothing to do by hand:** no deploy file to fetch again, no new variable. Installations with automatic updates take this version by themselves.
- **One small database migration** adds an empty column for the new setting. It runs at the start; every update makes a backup first.
- **Desktop app 0.11.1 follows this release** with the new field in the administration and the sentences under the forms. Older apps keep working; they just do not show the link.
- No newer Squorli Directory is needed.

## New

- **Link to your privacy policy (Administration > Server).** As the operator you answer for the data of server accounts (`~name`). Enter the address of your privacy policy (https only) and the form for a new server account says "By creating the account you accept this server's privacy policy", with the link. Leave it empty and the form says nothing, as before.
- **The form for a Squorli account inside the client** (for members from before server accounts) now links the Directory's privacy policy, as the Directory's own account page does.

## Improved

- **The source repository is now github.com/danielklessa/squorli.** Links in the client, the install script and the Windows package point there. The old address keeps redirecting, and the container image keeps its name `ghcr.io/danielklessa/squorli-server`, so nothing changes for existing installations.
