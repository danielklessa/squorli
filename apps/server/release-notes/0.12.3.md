A maintenance release: LiveKit 1.13.10 and updated libraries in the image, a security fix in a URL parser, and the package for Windows with Node.js 24.22.1. No migration and no new variable. Desktop app 0.15.1 follows with a security fix of its own.

## Before you update

- **Nothing to do:** no migration, no new variable, no file of yours to change. Installations with automatic updates take this version by themselves once it is published.
- **LiveKit 1.13.10:** the pinned LiveKit version moves from 1.13.9 to 1.13.10. On Linux, `squorli update` replaces `compose.yml` when it is still the one the previous image brought (a file you changed by hand is kept, and the new one is written next to it as `compose.yml.new`) and recreates the LiveKit container. On Windows the package carries the new program. A Portainer stack takes the new tag when you update its stack file; it keeps working with 1.13.9 until then.
- **Desktop app:** 0.15.1 follows with the same client and a security update of its runtime. Older apps keep working with this server; the browser client comes with the server. No newer Squorli Directory is needed.

## Improved

- **LiveKit 1.13.10.** The media server inside the installation moves up one maintenance release, with fixes in the handling of simulcast layers, retransmission requests and padding for dropped packets.
- **Updated libraries.** The LiveKit client 2.23, the video processors and the icon set are current.
- **The package for Windows** carries Node.js 24.22.1 (24.21.0 before) and LiveKit 1.13.10; `squorli update` installs both.

## Fixed

- **A URL parser's security fix.** The URL library the server's web framework uses (fast-uri) is updated to the versions that no longer let a crafted relative address re-parse as an absolute one with a scheme (CVE-2026-110725).
