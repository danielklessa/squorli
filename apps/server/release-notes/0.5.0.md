One new feature for the client this server serves; nothing changes on the server itself.

## Before you update

- **Nothing to do:** no database migration, no new variable, no change to the deploy files. `squorli update` is enough.
- **A new desktop app (0.8.0) follows after this server.** Older apps keep working; blocking reaches their users only with the new app, and browser users with this update.
- **No newer Squorli Directory is needed.** With a directory account the block list is stored inside the account's encrypted settings, which every current directory already holds.

## New

- **Block a member.** Everybody can block another person for themselves: right-click a member (or open their profile) and choose "Block", or block after reporting a message or a member. From then on that person's messages show folded ("Blocked message from …", with "Show" to open one), they do not mark a channel unread or count as a mention, and in a voice channel you no longer hear them. With a Squorli account the directory also refuses their friend requests. The blocked person is not told, and your server never learns whom its members block: the list is kept encrypted in the member's directory account (so it holds on every server and device), or on the device for a server account. Settings > Blocked lists whom you blocked and lifts a block. Blocking is the member's own view, not moderation: kick, ban and reports work as before.
