Security release after the audit of 5 October 2026: the link preview parser can no longer stall the server, password backups of server accounts use Argon2id, the deploy templates and the installer are hardened. Update when you can; a security advisory for the link preview issue follows on GitHub once this version has been out for a while.

## Before you update

- **Nothing to do by hand** for an installation made with the install script or the Windows package: no database migration, no new variable. Installations with automatic updates take this version by themselves once it is published.
- **Until you update:** `LINK_PREVIEWS=false` in the `.env` (and a restart) closes the link preview issue on an older version; remove the line after the update.
- **The templates changed** (`deploy/portainer.yml`, `deploy/proxies/remote-proxy.ports.yml`, `.env.example`): the Portainer stack now publishes 3000 and 7880 on `127.0.0.1` by default (a proxy on another host needs `PROXY_BIND_IP` = this host's LAN or VPN address), the overlay for a proxy on another host refuses to start without `PROXY_BIND_IP`, and `TRUSTED_PROXIES` defaults to `auto` (the stack's own Docker network and loopback; add a proxy on another host as `auto,<its IP>`). An existing `.env` keeps its values; the Portainer stack keeps running with your variables, paste the new file over it when you like.
- **`RATE_LIMIT_FACTOR=0`** (rate limits off, for load tests) stops a production server from starting now; set a value above 0 or remove the line.
- **The install script** takes the deploy files out of the signed image from now on (`docker create` + `docker cp`, after the signature check) instead of downloading them from GitHub; its next run against this version does that by itself. `squorli update` is unchanged.
- **Desktop app:** version 0.12.6 is recommended (it carries the same fixes for the previews of direct messages and the Argon2id backups); older apps keep working with this server.
- The public Squorli directory was updated the same day; no action for you.

## Security

- **Link previews could stall the server** (audit H-1): a crafted web page of 512 KB, posted as a link by any member, kept the server's single thread busy for about 20 seconds, during which nothing was answered. The page head is now read in one linear pass and in a worker thread with a time budget of one second; a page that is not read in time gets no preview, nothing else.
- **Secrets of the browser client are sealed** (M-2): a browser keeps the identity's seed, the server accounts and the session tokens in localStorage only as ciphertext under a key the browser holds in IndexedDB and never exports. The desktop app keeps its platform store.
- **Password backups of server accounts use Argon2id** (L-1) instead of PBKDF2: 64 MiB of memory per guess make stolen databases far harder to crack. Existing backups keep working and are stored anew with Argon2id after the next sign-in with the password; a new or changed password is at least 12 characters now.
- **Device-bound sessions sign the request body** (L-6, version 2 of the proof): a captured proof fits its own request with its own body and nothing else. Clients from before keep working.
- **Smaller fixes:** the debug panel masks incoming frames too (L-7); a message with thousands of closing parentheses no longer costs the server a square-time scan (L-9); web radio stations are read with the strict HTTP parser first and the lenient one only when they need it (L-18); every GitHub action of the release workflows is pinned by commit (M-4).

## Fixed

- **The audit's report** named a few templates and defaults; see "Before you update" for what changed for operators. The server's behaviour is otherwise the same as 0.10.3.
