A maintenance release: LiveKit 1.13.11 and updated libraries in the image, and the package for Windows with LiveKit 1.13.11. No migration and no new variable. Desktop app 0.15.2 follows with a fix for its title bar.

## Before you update

- **Nothing to do:** no migration, no new variable, no file of yours to change. Installations with automatic updates take this version by themselves once it is published.
- **LiveKit 1.13.11:** the pinned LiveKit version moves from 1.13.10 to 1.13.11. On Linux, `squorli update` replaces `compose.yml` when it is still the one the previous image brought (a file you changed by hand is kept, and the new one is written next to it as `compose.yml.new`) and recreates the LiveKit container. On Windows the package carries the new program. A Portainer stack takes the new tag when you update its stack file; it keeps working with 1.13.10 until then.
- **Desktop app:** 0.15.2 follows with the same client. Older apps keep working with this server; the browser client comes with the server. No newer Squorli Directory is needed.

## Improved

- **LiveKit 1.13.11.** The media server inside the installation moves up one maintenance release: it picks the right DTLS role when ICE lite is on, times its RTCP reports from the monotonic clock, keeps the stream's start offset right when a simulcast source switches, no longer offers AV1 to Firefox, and is rebuilt on a patched base image after the eMudhra certificate compromise. Voice, camera and screen share were checked against it.
- **Updated libraries.** The web framework's upload and static-file plugins, the LiveKit server SDK and the icon set are current.
- **The package for Windows** carries LiveKit 1.13.11; `squorli update` installs it.
