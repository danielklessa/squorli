A fix for members who lost the whole interface when the radio started or ended, and a way back should the interface ever fail again.

## Before you update

- **Nothing to do by hand:** no migration, no new variable, no file to fetch. Installations with automatic updates take this version by themselves.
- **Desktop app 0.9.2 follows** with the same two changes. The app brings its own copy of the client, so members who use it are rid of the error with that version, not with this update of the server.
- No newer Squorli Directory is needed.

## Improved

- **A notice instead of an empty window.** Should an error ever take the interface down, a card says so and offers "Reload", which brings everything back. A voice connection that is running ends with the reload; the notice says so. The error itself can be read under "Technical details" for a report.

## Fixed

- **The interface no longer vanishes when the radio starts or ends.** Members who may not control the radio and had the voice channel's stage open lost the whole interface at that moment: only the background was left until they reloaded the page. Members with the permission were not affected.
