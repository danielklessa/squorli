A fix for channel permissions on servers whose structure came from Discord: whoever may manage a channel can set its permissions again, even when the channel carries an entry for their own role. Desktop app 0.13.2 brings the client's part.

## Before you update

- **Nothing to do.** No database migration, no new variable: installations with automatic updates take this version by themselves once it is published.
- **Desktop app:** 0.13.2 shows the entries you cannot change as locked, with the reason. Older apps keep working with this server; the browser client that comes with the server has everything.

## Fixed

- **Channel permissions on imported servers.** Whoever may manage channels but is not an administrator got "Diese Rolle steht über deiner." for every switch in a channel's permissions as soon as the channel carried an entry for a role at or above their own, which a Discord import leaves there for the editor's own role. The server checked that rank rule for every entry of the list, the untouched ones included. Now only the entries you change or remove count; an entry for a role above you stays as it is, and the rest of the list can be edited.
