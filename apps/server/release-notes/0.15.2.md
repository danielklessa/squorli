One fix for screen shares in fullscreen: the volume control of a stream you watch can be used again. No migration, no new variable. Desktop app 0.17.3 follows with the same client.

## Before you update

- **Nothing to do by hand.** Installations with automatic updates take this version by themselves once it is published. There is no database migration and no new variable.
- **Desktop app:** 0.17.3 follows with the same client. Older apps keep working with this server; they just lack the fix. The browser client comes with the server, so members in a browser get it at once.

## Fixed

- **The volume control in fullscreen.** Since 0.15.1 the strip for switching streams along the bottom edge took the mouse before it reached the volume slider of the stream in fullscreen, so the slider could not be moved. The volume control now lies above that strip, in the stage and in a pop-out window.
