The camera preview shows the background blur again and moves into the settings too, you can see your own picture unmirrored, a sound announces a new screen share, and the game display can be limited to chosen people. The image and the package for Windows run on Node.js 26. No migration and no new variable. Desktop app 0.16.0 follows with the same client.

## Before you update

- **Nothing to do:** no migration, no new variable, no file of yours to change. Installations with automatic updates take this version by themselves once it is published.
- **Node.js 26:** the image and the package for Windows carry Node.js 26 (LTS) instead of 24. Nothing to configure; on Windows `squorli update` installs it with the package.
- **Windows installations from before 0.10.0** update again: their setup stopped with an error at the storage limit's question. If you worked around it with `STORAGE_QUOTA_MB` in `.env`, you can leave that line as it is.
- **Desktop app:** 0.16.0 follows with the same client. Older apps keep working with this server; the browser client comes with the server.
- **Who may see my game** needs this server version for the members of your server, and a Squorli Directory that knows the rule for friends (directory.squorli.com does). A client with such a rule tells an older server nothing about the game instead of showing it to everybody.

## New

- **Who may see my game.** In Settings > Spiele a member chooses "Alle", "Nur ausgewählte" or "Alle außer" and fills the list from friends and server members, or right-clicks a person and picks "Mein Spiel verbergen" or "Mein Spiel zeigen". The server hands the game only to the members the rule allows. For that it receives the keys of the listed people with each game report and keeps them in memory only; nothing of it is stored. The lists themselves follow the Directory account, encrypted. Reporting a game needs the desktop app.
- **A sound for a new screen share.** When somebody else in your voice channel starts sharing their screen, three short rising notes play. It has its own switch with a preview in Settings > Töne and stays silent while you are deafened or may not watch video in the channel.
- **Camera preview in the settings.** Settings > Kamera shows your picture with the chosen background after "Vorschau starten", before you turn the camera on in a channel.
- **Your own picture unmirrored.** "Mein Kamerabild gespiegelt anzeigen" in Settings > Kamera and in the dialog at switch-on decides whether you see yourself as in a mirror or the way the others see you. The others always get your picture unmirrored.

## Fixed

- **The camera dialog shows the background blur again.** The preview in "Kamera einschalten" ignored "Leicht unscharf" and "Stark unscharf" since the blur's files are served by the server itself; in the channel the blur worked all along.
- **Windows: updating an installation from before 0.10.0.** The setup of the new package no longer stops at the storage limit.
