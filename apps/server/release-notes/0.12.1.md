Everyone in a voice channel equally loud at the press of a button, a microphone level that can be lowered as well as raised, and chosen audio devices that are no longer lost when Windows sets a device up again. No migration and no new variable. Desktop app 0.14.2 brings the same client to the app.

## Before you update

- **Nothing to do:** no migration, no new variable, no change to the deploy files. Installations with automatic updates take this version by themselves once it is published.
- **Desktop app:** 0.14.2 carries the same client. Older apps keep working with this server but show none of the changes below; the browser client comes with the server. No newer Squorli Directory is needed.

## New

- **All speakers equally loud.** A new button at the right end of the stage's button bar brings everyone speaking in the voice channel to the same level: quiet speakers are raised, loud ones lowered, each to one fixed level that does not depend on who else is there. While it is on, a slider next to it sets that level from 50 to 150 %. The volume per person in the right-click menu still works on top, so one speaker can be put above or below the others. It applies to voices only, not to shared screens or the web radio. Off until a member turns it on; kept per device, also under Settings > Voice and audio > Output.

## Improved

- **The microphone level can be lowered.** Settings > Voice and audio > Microphone level now runs from 1 to 600 % in whole percent, with 100 % marked under the slider, so a microphone that is too loud can be turned down as well as up. The automatic still only raises a quiet microphone.

## Fixed

- **Chosen audio devices are found again.** When Windows sets a device up again (after a driver or Windows update, or on another USB port) it gets a new identity, and Squorli fell back to the system's default device, so the output had to be chosen again. Squorli now remembers each chosen device's name and finds it again by that name, for the microphone, the outputs and the camera. A choice made before this version is remembered by name from its first start on.
