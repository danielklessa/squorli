A fix for server account passwords on other servers, and updated libraries.

## Before you update

- **Nothing to do by hand** for an installation made with the install script or the Windows package: no database migration, no new variable, no deploy file to fetch again. Installations with automatic updates take this version by themselves once it is published.
- **Old server accounts may be locked out of new devices.** The web client now refuses a server account whose password is not tied to the server (see "Fixed"). Server accounts made before 25 September 2026 had such a password, and the client tied it to the server at the next sign-in with the password; an account that has not signed in with its password since cannot sign in on a new device any more (devices that are signed in stay signed in, and there is no way back in the client). To see whether you have any, run `select handle from local_accounts where backup_params->>'bound' is null;` in the server's database. On a server whose members are all known, this will be none.
- **Desktop app:** older apps keep working. They sign in the way they always did; desktop app 0.11.3 has the same fix as the browser client of this release.
- No newer Squorli Directory is needed.

## Improved

- **Updated libraries:** the camera effects helper of the web client, a URL library of the web server, the icon font (a few icons may look slightly different) and the build tools. The base image of the container is now a fixed build of Node 24, so the same source gives the same image.

## Fixed

- **A password you use elsewhere is worth nothing to a foreign server.** A server account's password is turned into keys with a salt and a number of rounds that the server names. A server that was not trusted could name the same values the Squorli directory shows for a handle and so collect the key that opens that directory account's backup from someone who uses one password for both. The client now only accepts a password scheme that is tied to the server's address and no longer ties old accounts to it by itself.
