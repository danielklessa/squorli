The libraries of the server and of its web client are brought to their current major versions: React 19 for the client, the current Lucide icon set, zod 4, noble-ed25519 3, @fastify/multipart 10, Vite 8 and Vitest 5 for building and testing. Nothing changes in use. Desktop app 0.13.3 carries the same client.

## Before you update

- **Nothing to do.** No database migration, no new variable: installations with automatic updates take this version by themselves once it is published.
- **Desktop app:** 0.13.3 is the matching app. Older apps keep working with this server; the browser client that comes with the server has everything.

## Improved

- **Updated libraries.** The web client runs on React 19 and uses the current Lucide icon set; the server's libraries for uploads, validation and signatures are on their current major versions, as are the GitHub actions that build and sign the releases.
- **Request methods named in the CORS answer.** The server now lists the methods the desktop app uses (GET, HEAD, POST, PUT, PATCH, DELETE) itself instead of relying on the CORS library's default, which the library's next version narrows to GET, HEAD and POST.
