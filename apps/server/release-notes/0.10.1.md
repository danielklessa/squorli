## Before you update

- **Nothing to do by hand.** No database change, no new variable. Installations with automatic updates take this version by themselves once it is published.
- **Desktop app:** older apps keep working. Desktop app 0.12.4 brings the same client changes to the app; the browser client comes with the server.
- **Directory:** the live server list and the check of reported direct messages need the Squorli Directory of 4 October 2026 or newer (directory.squorli.com has it); with an older directory those two simply stay as they were.

## New

- **Tiles in your own order.** In a voice channel's tile view, drag a tile where you want it, or move the focused tile with Alt and an arrow key. Your own tile stays first, newcomers join at the end, and the order is forgotten when you leave the channel. The speaker view's strip follows the same order.

## Improved

- **The server list follows your account at once.** A changed server icon, a server you left on another device and the order of your server list now show up within moments on every signed-in client, not only after a restart.
- **Direct messages hide their length.** Messages are padded to 1 KB steps before they are encrypted, so the directory no longer learns how long a message is. Older apps read them as before.
- **A reported direct message is checked at the directory.** The report carries the message as the directory delivered it; the directory compares it with what it stores and tells its operator whether the message existed like that and who sent it. What the text says stays the reporter's statement.
- **Reports on this server expire.** An open report nobody judged for 180 days is closed by the server and marked so in the queue; a closed report is deleted a year after it was closed. Until now the entry stayed forever.
