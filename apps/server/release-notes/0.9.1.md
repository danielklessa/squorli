Hardened containers, a storage quota by default, and the server icon checked by its bytes (security audit, stage 3).

## Before you update

- **Nothing to do by hand** for an installation made with the install script or the Windows package: no database migration. Installations with automatic updates take this version by themselves once it is published.
- **The deploy files changed** (`deploy/compose.yml`, `deploy/portainer.yml`): the containers now run read-only with no privileges beyond a plain process. An installation made with the install script takes the new files with the installer's next run (`curl ... | sudo bash`, "Einstellungen ändern"); until then it runs as before, which is fine.
- **Portainer:** paste the new `deploy/portainer.yml` over your stack and update it; the volumes and your variables stay. The changes are container settings only (`read_only`, `cap_drop`, `no-new-privileges`, a tmpfs for `/tmp`), attachments and pictures live in the volume as before. A Portainer stack has no installer, so it gets no storage quota by itself: set `STORAGE_QUOTA_MB` in the stack's variables if you want one (see "New").
- **Desktop app:** older apps keep working. One new text (the reason when the Squorli directory refuses a reserved handle) comes with the next desktop app.
- No newer Squorli Directory is needed.

## New

- **A storage quota by default.** A fresh installation with the install script or the Windows setup gets `STORAGE_QUOTA_MB` = 80 % of the space free at that moment, shown in the summary before you confirm; change it in the `.env` any time. An existing installation keeps running without a quota: set the variable yourself if one member should not be able to fill the disk.
- **Hardened containers.** The app server, LiveKit and the bundled Caddy run with a read-only filesystem and without capabilities (Caddy keeps the one it needs for ports 80 and 443), Postgres without privilege escalation.

## Fixed

- **The server icon is checked by its bytes** (PNG, JPEG, WebP, GIF), not by the type the upload claims; what is stored and served is the real type.
