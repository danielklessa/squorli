Voice channels that show what you choose: a screen share is large only once you click it, and a click pins a tile and releases it again. The radio gets an equalizer behind the stage and an icon that turns it off and on for you, and one button in the server list adds a server by address or from the directory. No migration and no new variable. Desktop app 0.14.0 brings the same client to the app.

## Before you update

- **Nothing to do:** no migration, no new variable, no change to the deploy files. Installations with automatic updates take this version by themselves once it is published.
- **Desktop app:** 0.14.0 carries the same client. Older apps keep working with this server but show none of the changes below; the browser client comes with the server. No newer Squorli Directory is needed.

## New

- **Pinning in the speaker view.** A screen share, and the radio's Twitch or YouTube video, no longer takes the large place by itself: without a pin the speaker view shows whoever is speaking. Click a tile to pin it large, click the large tile again to release it, and the large place follows the speaker again. The radio's video has its pin button next to its pop-out button, shown when the pointer is over the video.
- **Radio equalizer.** While a station plays (not a Twitch or YouTube source), soft bars with a few particles move with its sound behind the tiles. It is off until a member turns it on with the button at the left end of the stage's button bar; the choice is kept per device. It needs a station that lets the browser read its sound; other stations play as before, without the equalizer and its button.
- **One button to add a server.** The plus at the bottom of the server list now opens one dialog for both: type a server's address, an invite link or a squorli:// link and press Enter, or type words to search the servers published in the directory below. The compass button is gone.

## Improved

- **The radio's icon turns the radio off and on for you.** While a station plays, a click on the radio icon in the stage's head turns it off for you and a second click turns it back on; the station's name next to it opens the radio menu as before.
- **A quieter stage head.** The number of participants and the audio quality moved into the tooltip of an info icon next to the channel's name, and the switch between speaker and tile view shows icons.
- **`squorli update` on Linux brings new deploy files.** A new LiveKit or PostgreSQL version named in the deploy files now arrives with `squorli update` as well: after the backup and the signature check it takes over the deploy files you did not change (keeping the old copy) and leaves a file you changed by hand as it is, with the new one next to it as `.new`; a new major version of PostgreSQL stops the update with a note. The `squorli` command also keeps its language when called as `./squorli`. Installations made before get this once they run the install script again and choose "Update".
