The title bar of the see-through window reacts to a double click again, and the app's runtime is current. Works with every server version.

## Fixed

- **Double click on the title bar (Windows).** With the window background "Durchsichtig" (Settings > Ansicht) a double click on the app's title bar now maximizes the window and a second one restores it, as Windows does for other windows; Win+Up maximizes it too. Windows cannot snap a see-through window (dragging to an edge, Win+Left/Right, snap layouts), so these stay with the opaque and the Mica background, which keep all of Windows' window handling.
