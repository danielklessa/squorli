## Improved

- **Signed installers.** On Windows, the installer, the app and its helper programs carry a code signature by Daniel Klessa (Open Source Developer), issued by Certum. Windows shows that name instead of "Unknown publisher", and from this version on the app installs an update only when the downloaded installer carries the same signature. SmartScreen may still warn for a while: the certificate is new and has to earn its reputation first. On Linux, the AppImage and the deb package come with a signature file (*.asc) that you can check against the key published on squorli.com.

Nothing else changes; this version works with every server version.
