## New

- **The leave sound when you close the app in a voice channel.** Closing the window or quitting from the tray icon while you sit in a voice channel now plays the leave sound before the app goes, and tells the server you left, so the others hear you go instead of watching you drop. The app waits for that a moment at most. Closing into the tray icon keeps you in the channel, as before.
- **Administration > Server > Limits.** Shows what the server's operator has set as limits for storage, seats in voice channels and members, and how much of that is in use. Needs Squorli Server 0.8.0 or newer on that server; older servers show no such section.

## Improved

- **A refused upload says why.** A file that is too large, or a server whose storage is full, gets a sentence with the file's name instead of a bare error code. The storage message needs Squorli Server 0.8.0.
- **Joining a voice channel when every seat of the server is taken says so** instead of failing with a code. Needs Squorli Server 0.8.0; older servers have no such limit.
