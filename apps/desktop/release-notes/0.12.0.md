## Improved

- **Your sign-in is tied to this device.** With a server of version 0.10.0 or newer, the session the app holds works only together with this device's own key: every request and the live connection carry a fresh signature of it. A session token copied out of the app's data, a screenshot or a log opens nothing without the device. You notice nothing of it; with a server from before, the app signs in as before.
- **Sessions that were not used for 14 days end.** Such a server also ends a session that lay unused for 14 days (the operator can change that); the app then shows the sign-in again. A running app counts as use.
