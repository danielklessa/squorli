The first version for macOS. Works with every server version.

## New

- **Squorli for macOS.** Two downloads on the download page: one for Macs with an Apple chip, one for Intel Macs; macOS 13 or newer. The app is not notarized by Apple yet, so macOS refuses the first start: open Squorli once, then allow it under System Settings > Privacy & Security > Open Anyway. After a new version macOS also asks once whether Squorli may use its keychain entry; choose Always Allow. The Mac app does not update itself: it shows a notice in the title bar and sends you to the download page. Not on the Mac: the sound of a single window in a screen share, push-to-talk while another program has the focus, game detection and start with the system.
