Emoji reactions, reaction roles, collapsible categories and notices. The three channel features need Squorli Server 0.11.0 on the server you use; against an older server the app works as before, without them.

## New

- **Emoji reactions.** React to a message with the emoji picker from the message's toolbar; the chips under the message show who reacted and a click on a chip joins or leaves it. In direct messages, reactions show for friends whose app has them too. Whether you may react in a channel is up to the server (the right "Reagieren").
- **Reaction roles.** A server can tie an emoji on a particular message to a role, so you accept its rules with one click on that emoji. Moderators set it up with the shield in a message's toolbar or under Verwaltung > Reaktionsrollen.
- **Collapsible categories.** Click a category's heading in the channel list to fold it. The folded heading shows how many unread messages the category holds, a badge for mentions, and how many people sit in its voice channels; the channel you are reading stays visible. Your choice is kept per server on this device.
- **Notices.** With the right "Hinweise setzen", any message of a channel can be shown as a notice: without avatar and name, only the time at the left edge and the text next to it. The megaphone in the message's toolbar sets it and takes it back.
