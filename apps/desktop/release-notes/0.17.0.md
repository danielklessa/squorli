The app shows what plugins add to a server: commands in the message field, entries in a member's menu, messages under a plugin's own name, and the Plugins tab in the administration. Works with every server version; plugins need Squorli Server 0.14.0 on the server.

## New

- **Slash commands.** On a server with plugins, type `/` in the message field to see the commands its plugins offer, with what each does and which plugin it belongs to. Some run at once, some take the rest of the line, some open a small form. A command's answer appears above the message field and only you see it.
- **Plugin entries in the member menu.** A right click on a member shows what plugins add there, for example "Rolle auf Zeit…" of the timed roles plugin. Every dialog a plugin opens says which plugin it comes from.
- **Messages written by a plugin** carry the plugin's name, a "Plugin" mark and who caused them.
- **Administration > Plugins.** Owners install a plugin from a file or from the list "Verfügbar", read what it may do before switching it on, and find its settings, its tables and its log on its page. Members with the right to manage the server see the tab and edit settings.
- **A date field with a calendar** in forms of plugins, with a switch to leave the year out where a plugin allows it (the birthdays plugin does).
