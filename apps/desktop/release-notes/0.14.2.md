Everyone in a voice channel equally loud at the press of a button, a microphone level that can be lowered as well as raised, and chosen audio devices that are no longer lost when Windows sets a device up again. Works with every server version; Squorli Server 0.12.1 carries the same client for the browser.

## New

- **All speakers equally loud.** A new button at the right end of the stage's button bar brings everyone speaking in the voice channel to the same level: quiet speakers are raised, loud ones lowered, each to one fixed level that does not depend on who else is there. While it is on, a slider next to it sets that level from 50 to 150 %. The volume per person in the right-click menu still works on top, so you can put one speaker above or below the others. It applies to voices only, not to shared screens or the web radio. Off until you turn it on; also under Settings > Voice and audio > Output.

## Improved

- **The microphone level can be lowered.** Settings > Voice and audio > Microphone level now runs from 1 to 600 % in whole percent, with 100 % marked under the slider, so a microphone that is too loud can be turned down as well as up. The automatic still only raises a quiet microphone.
- **The debug button moved into the title bar,** next to the window buttons, so the channel's header keeps its full width.

## Fixed

- **Chosen audio devices are found again.** When Windows sets a device up again (after a driver or Windows update, or on another USB port) it gets a new identity, and the app fell back to the system's default device, so the output had to be chosen again. The app now remembers each chosen device's name and finds it again by that name, for the microphone, the outputs and the camera. A choice made before this version is remembered by name from its first start on.
