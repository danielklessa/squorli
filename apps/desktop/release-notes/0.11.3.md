## Improved

- **Updated libraries:** the camera effects (background blur) helper and the icon font, so a few icons may look slightly different.

## Fixed

- **A password you use elsewhere is worth nothing to a foreign server.** When you sign in to a server account (`~name`), the app turns your password into keys using values the server names. The app now only accepts a scheme that is tied to that server's address; before, a server that was not trusted could have used values that match your Squorli account at the directory and so collected the key that opens its backup, if you used the same password for both. Server accounts made before 25 September 2026 that have not signed in with their password since may no longer sign in on a new device (ask the server's operator); devices that are signed in stay signed in.
