## New

- **Tiles in your own order.** In a voice channel's tile view, drag a tile where you want it, or move the focused tile with Alt and an arrow key. Your own tile stays first, newcomers join at the end, and the order is forgotten when you leave the channel. The speaker view's strip follows the same order.

## Improved

- **The server list follows your account at once.** A changed server icon, a server you removed on another device and the order of your server list now show up within moments on every signed-in client, not only after a restart. Needs the Squorli Directory of 4 October 2026 or newer (directory.squorli.com has it).
- **Direct messages hide their length.** Messages are padded to 1 KB steps before they are encrypted, so the directory no longer learns how long a message is.
- **A reported direct message is checked at the directory.** The report carries the message as the directory delivered it; the directory compares it with what it stores and tells its operator whether the message existed like that and who sent it. What the text says stays your statement.
- In a server's report queue, a report the server closed by itself after 180 days says so.

Works with every server version.
