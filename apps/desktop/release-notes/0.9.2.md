## Improved

- **A notice instead of an empty window.** Should an error ever take the interface down, a card says so and offers "Reload", which brings everything back; the title bar stays, so the window can still be moved and closed. A voice connection that is running ends with the reload; the notice says so. The error itself can be read under "Technical details" for a report.

## Fixed

- **The interface no longer vanishes when the radio starts or ends.** If you may not control the radio and had the voice channel's stage open, the whole interface disappeared at that moment and only the window's background was left until the app was restarted. Members with the permission were not affected.
