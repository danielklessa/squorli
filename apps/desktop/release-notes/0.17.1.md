The app catches up with Squorli Server 0.15.0: the catalogue of signed plugins, cards, and lists in a plugin's settings. Works with every server version; what is listed here needs Squorli Server 0.15.0 on the server.

## New

- **The plugin catalogue.** In Administration > Plugins, "Katalog öffnen" lists the plugins Squorli signed, with a search field. An owner installs or updates one with a click; the server downloads and checks the file.
- **Cards.** A plugin's message can be a card with a title that links somewhere, a formatted text and pictures. The game news plugin of the catalogue posts them: patch notes, free games and new graphics drivers. The pictures come from your server, never from a foreign host.
- **Whose plugin it is.** A plugin that carries Squorli's signature shows "Von Squorli" or "Von Squorli geprüft" in the list, on its page and in the confirmation before it is switched on. A plugin that may fetch from the internet names every host it asks there.

## Improved

- **Lists in a plugin's settings.** Where a plugin asks for a list (the games of the game news plugin), entries are added and removed in place, and what the plugin finds wrong with an entry stands at the field.
