## New

- **Notifications while a game runs in full screen are your choice.** Settings > Sounds, "Also while a game or another application runs in full screen": off by default, so a full screen game or presentation is no longer interrupted by a notification (Windows).

## Fixed

- **Notifications come from "Squorli"** with the app's icon on Windows, no longer from "electron".
- **Uninstalling removes the app's registry entries** (notification name, `squorli://` links, start with the system). An update keeps them.
